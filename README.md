# 🎮 Game_Fast_2026
Bem-vindo ao repositório oficial do Game Fest 2026, uma landing page moderna e responsiva desenvolvida como projeto acadêmico para a divulgação de um evento fictício de games.

🚀 Sobre o Projeto

O Game Fest 2026 é o maior evento gamer da década! Esta plataforma apresenta todas as informações essenciais sobre o evento de forma imersiva e interativa. O layout foi desenvolvido com foco na estética "Gamer", utilizando Dark Mode, efeitos de brilho em Neon e botões Sci-Fi.

Funcionalidades do Site:

Programação Completa: Um cronograma detalhado de 3 dias de evento.

Arena de Campeonatos: Exposição dos jogos participantes (Valorant, EA FC 26 e Street Fighter 6).

Atrações Especiais: Seções dedicadas a concursos de Cosplay, Meet & Greet, Áreas Retro e Drops de Loot.

Sistema de Ingressos: Tabela de preços clara com os benefícios de cada classe de passe (Básico, VIP e Lenda).

Formulário de Contato Interativo: Validação de envio e mensagens de sucesso tratadas diretamente via JavaScript, sem recarregar a página.

🛠️ Tecnologias Utilizadas

Este projeto foi construído em um único arquivo estruturado (index.html), aplicando as melhores práticas de desenvolvimento front-end:

HTML5: Estruturação semântica de todo o conteúdo.

Tailwind CSS (via CDN): Framework utilitário de CSS usado para garantir 100% de responsividade (Mobile First), definindo margens, cores, grids e tipografia.

CSS3 Customizado: Regras de estilo adicionadas localmente para manipular as animações keyframes, gradientes e propriedades de sombra (box-shadow e text-shadow) simulando o visual "Neon".

JavaScript (Vanilla): Utilizado para manipulação do DOM. Gerencia a abertura e fechamento do menu em dispositivos móveis e a interação do formulário de contato.

Google Fonts: Utilização das fontes Orbitron (para títulos) e Inter (para textos).
