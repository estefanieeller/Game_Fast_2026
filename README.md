# 🎮 Game Fest 2026

Landing page interativa e responsiva para a divulgação do evento fictício de games **Game Fest 2026**.

> 🎓 **Nota:** Este projeto foi desenvolvido como um trabalho acadêmico para o curso de **Sistemas de Informação da UFF** (Universidade Federal Fluminense).

## 🚀 Sobre o Projeto

O **Game Fest 2026** é projetado para ser o maior evento gamer da década! Esta plataforma web apresenta todas as informações essenciais sobre o evento de forma imersiva e interativa. O layout foi desenvolvido com foco na estética "Gamer", utilizando Dark Mode, efeitos de brilho em Neon e botões Sci-Fi.

### 🕹️ Funcionalidades do Site

* **Programação Completa:** Um cronograma detalhado de 3 dias de evento.
* **Arena de Campeonatos:** Exposição dos torneios e jogos participantes (*Valorant, EA FC 26 e Street Fighter 6*).
* **Atrações Especiais:** Seções dedicadas a concursos de Cosplay, Meet & Greet, Áreas Retro e Drops de Loot.
* **Sistema de Ingressos:** Tabela de preços com os benefícios de cada classe de passe (Básico, VIP e Lenda).
* **Formulário de Contato Interativo:** Validação de envio e mensagens de sucesso tratadas diretamente via JavaScript, sem recarregar a página.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído em um formato *Single-Page Application* (SPA) simples, aplicando as melhores práticas de desenvolvimento front-end:

* **HTML5:** Estruturação semântica de todo o conteúdo.
* **Tailwind CSS (via CDN):** Framework utilitário de CSS usado para garantir 100% de responsividade (Mobile-First), definindo margens, cores, grids e tipografia.
* **CSS3 Customizado:** Regras de estilo adicionadas para manipular animações `keyframes`, gradientes e propriedades de sombra (`box-shadow` e `text-shadow`), simulando o visual "Neon".
* **JavaScript (Vanilla):** Utilizado para manipulação do DOM (gerenciamento do menu *hamburger* em dispositivos móveis e interatividade do formulário de contato).
* **Google Fonts:** Utilização das fontes `Orbitron` (para títulos) e `Inter` (para textos).
